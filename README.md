# 🌐 مشروع نَسِيج | Naseej-Telecom-AI
> **AI-Powered Automated Diagnostics & Self-Healing Network Ecosystem for Algérie Télécom.**

---

## 📌 1. الرؤية العامة للمشروع (Executive Summary)
مشروع **"نَسِيج" (Naseej)** هو نظام بيئي ذكي مصمم خصيصاً لتطوير البنية التحتية وخدمات الزبائن لشركة **اتصالات الجزائر (Algérie Télécom)**. يعتمد المشروع على تقنيات **الذكاء الاصطناعي التشغيلي (AIOps)**، **والحوسبة الطرفية (Edge Computing)** لتحويل الشبكة من نظام تفاعلي تقليدي (Reactive) إلى شبكة ذاتية الشفاء وتنبؤية (Proactive Self-Healing Network).

---

## ⚡ 2. الهندسة المعمارية للنظام (Core Architecture & Modules)

المشروع مبني على معايير هندسية دقيقة مقسمة إلى وحدات برمجية (Modules):

### 🔹 أ. نواة إدارة وتشخيص خطوط الزبائن (`naseej_core.py`)
* **مساعد ذكي محلي (Local NLP Agent):** يفهم اللهجة الجزائرية الدارجة للزبائن (مثل: "الكونيكسيون عيانة"، "الأنترنت مقطوعة").
* **التشخيص الذاتي (Self-Healing):** فحص الروتر (CPE) وإعادة ضبط المنافذ (Port Refresh) آلياً دون تدخل بشري (Zero-Touch Resolution).

### 🔹 ب. محرك التنبؤ بالأعطال الضوئية (`predictive_engine.py`)
* مطبق طبقاً لمعايير الاتحاد الدولي للاتصالات **ITU-T G.984 (GPON Compliance)**.
* يراقب القدرة الضوئية المستقبلة بوحدة **`dBm`** عبر التيليمتري.
* يحسب معدل التدهور اليومي (Daily Degradation Rate) للكابلات، ويتنبأ بانقطاع الخدمة قبل وقوعها بأيام.
* **الأتمتة الميدانية:** يولد تلقائياً تذاكر صيانة استباقية (Proactive Dispatch Tickets) لفرق التدخل الميداني مع تحديد السبب الفيزيائي (مثل الالتواءات أو الغبار في علب الـ FAT).
